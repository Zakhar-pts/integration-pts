# Матриця готовності v3
| Функція | Стан |
|---|---|
| Webhook приймання JSON, тест, історія | Реалізовано (локально не перевірено з Docker) |
| Кілька незалежних приймачів | Реалізовано |
| Telegram/TG bot повідомлення | Bot API, потрібен токен |
| Google Sheets append | API access token, ручне оновлення |
| CRM/HTTP | HTTPS endpoint, валідація URL з обмеженнями SSRF |
| ADSQuiz | Універсальний Webhook, не нативний OAuth |
| Facebook Lead Ads | Meta webhook + Graph API, потрібні permissions і Meta app review |
| Instagram Lead Ads | Ще не реалізовано |
| Google Ads lead forms | Ще не реалізовано |
| Gmail/OpenAI | API, потрібні облікові дані |
| Гарантована доставка/черги/retries | Ще не реалізовано |
| OAuth login та refresh | Ще не реалізовано |
